# Installation and runtime setup

The skill and the PDF translator are separate components. Installing the skill adds its workflow instructions to Codex; the local PDFMathTranslate checkout provides the `pdf2zh_next` command. Codex CLI must also be installed and logged in because the translator adapter runs `codex exec` subprocesses.

## Install the skill

Use the built-in `$skill-installer` with this GitHub folder URL:

```text
https://github.com/Aintme187/PDFMathTranslate-next/tree/codex-translator-adapter/skills/pdfmathtranslate-codex
```

The installer places `pdfmathtranslate-codex` under `$CODEX_HOME/skills` (normally `~/.codex/skills`). Restart or reload Codex if it does not appear after installation.

## Install the translator runtime

Requirements: Python 3.12 or newer within the repository's supported range, `uv`, and Codex CLI authenticated for the current user. Install Codex CLI and complete its normal login flow separately; do not copy credentials into PDFMathTranslate settings.

```powershell
git clone --branch codex-translator-adapter https://github.com/Aintme187/PDFMathTranslate-next.git
cd PDFMathTranslate-next
uv sync
uv run pdf2zh_next --help
codex --version
```

Run from the checkout with `uv run pdf2zh_next ...`. Select the `Codex` translation engine so PDFMathTranslate uses the adapter added in this branch. If a local Codex executable is not on `PATH`, the upstream Codex setting `codex_path` can point to it. The optional `codex_model` selects the model; omitted means Codex CLI's configured default.

## Operational notes

- Worker concurrency maps to PDFMathTranslate's existing `pool_max_workers` option. Omitted, the application uses its upstream default based on `qps` (4); each worker may launch a Codex CLI request. Reduce it if local resource use or request volume is too high.
- Source language defaults to `en`, target language to `zh`; pages default to the whole document; both bilingual and monolingual outputs are generated by default.
- Automatic glossary extraction is enabled by default and the extracted glossary is not saved by default. Use `--no-auto-extract-glossary` to disable extraction and `--save-auto-extracted-glossary` to save the generated glossary, if these options appear in the installed command's `--help`.
- The exact CLI spelling can evolve. Confirm it with `uv run pdf2zh_next --help` before invoking less common settings; do not guess flags from the Python setting names.
